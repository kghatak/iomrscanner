# Assets Directory

This directory contains application assets like icons and images.

## Icon Files (Optional)

To add custom icons to your builds, place these files here:

- `app_icon.ico` - Windows icon (recommended: 32x32, 48x48, 256x256 sizes)
- `app_icon.icns` - macOS icon (recommended: multiple sizes from 16x16 to 512x512)
- `app_icon.png` - Linux icon (recommended: 512x512 PNG)

## DMG Background (Optional)

- `dmg_background.png` - Custom background for macOS DMG installer

## Notes

- All icon files are optional
- Builds will continue without icons, using default system icons
- For professional distribution, custom icons are recommended
