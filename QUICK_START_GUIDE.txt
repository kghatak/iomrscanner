  BIGNAN MANCHA OMR READER - QUICK START GUIDE FOR WINDOWS USERS
================================================================================

EASIEST WAY TO RUN THE APPLICATION:
====================================

1. Extract the ZIP file to any folder (e.g., C:\Bignan_Mancha_OMR_Reader)

2. Double-click "run_app.bat"
   - The script will automatically set up everything
   - First time may take 5-10 minutes (installing dependencies)
   - After that, it will start quickly

3. That's it! The application window will open.

================================================================================
WHAT IF PYTHON IS NOT INSTALLED?
================================================================================

AUTOMATIC SETUP (RECOMMENDED):
-------------------------------
The script will automatically offer to download Python for you!

1. When you see "Download Python automatically (Y/N)?"
2. Type Y and press Enter
3. Python will be downloaded and set up automatically
4. No installation needed - it's portable Python!
5. The script will continue automatically

MANUAL SETUP (If automatic download fails):
--------------------------------------------
1. Go to: https://www.python.org/downloads/
2. Download Python 3.9 or later (click the big yellow button)
3. Run the installer
4. IMPORTANT: Check the box "Add Python to PATH" at the bottom
5. Click "Install Now"
6. Wait for installation to complete
7. Restart your computer
8. Try running run_app.bat again

================================================================================
WHAT IF SOMETHING GOES WRONG?
================================================================================

Problem: "Failed to install dependencies"
Solution: 
  - Make sure you have internet connection
  - Try running as Administrator (right-click run_app.bat > Run as administrator)
  - Check if antivirus is blocking the installation

Problem: "Application window doesn't open"
Solution:
  - Check the black console window for error messages
  - Make sure all dependencies installed successfully
  - Try closing and reopening run_app.bat

Problem: "PDF extraction doesn't work"
Solution:
  - Install Poppler (optional but recommended):
    1. Download from: https://github.com/oschwartz10612/poppler-windows/releases/
    2. Extract to C:\poppler
    3. Add C:\poppler\Library\bin to your system PATH

================================================================================
HOW TO UNINSTALL
================================================================================

To remove the application and all its components:

1. Double-click "uninstall.bat"
   - This will remove:
     * Virtual environment (venv folder)
     * Bundled Python (python folder - if auto-downloaded)
     * Temporary files and caches
     * Build artifacts (optional)

2. After uninstall.bat completes:
   - Delete the entire application folder to completely remove

3. Alternative method:
   - Run: run_app.bat --uninstall

NOTE: This will NOT remove:
   - System Python (if you installed it separately)
   - Your processed files in success/error folders
   - Application source files (delete folder manually)

================================================================================
MANUAL SETUP (FOR ADVANCED USERS)
================================================================================

If you prefer to set up manually:

1. Open Command Prompt (cmd) in this folder
2. Type: python -m venv venv
3. Type: venv\Scripts\activate
4. Type: pip install -r requirements.txt
5. Type: python main.py
